How to add a link

Links live in a file called links.json in your repository. Because it's one shared file, any change shows up on all your devices.

  1. Click Edit links.json on GitHub above (or open links.json in your repo and click the pencil icon).
  2. Add a new entry to the list. Each link looks like this:
{
  "title": "Site name",
  "url": "https://example.com",
  "category": "My Category",
  "desc": "Optional short note"
}

Put a comma after the previous entry's closing }, paste your new block, and keep everything inside the outer square brackets [ ]. Commit the change; the page updates within about a minute.

Tip: entries with the same category are automatically grouped together. To make a new group, just use a new category name.
