Search PubMed by keyword, date range, and journal. Results include a condensed summary of each abstract. Everything runs in your browser using PubMed's public API — no account or key needed. Use “Copy for AI summary” to paste results into Claude, ChatGPT, or Gemini for a deeper synthesis.

Want automatic scheduled email updates?

A static GitHub Pages site can't run on a schedule or send email on its own — it only runs when open in a browser. To get daily/weekly/monthly emails of new papers, add a GitHub Actions workflow (a scheduled job in your repo) that runs this same PubMed query and emails you the results.

Credentials stay safe when you use encrypted GitHub Secrets and an email App Password (a revocable, single-purpose credential — never your real login password). Secrets are encrypted, hidden from the repo and page source, and only decrypted inside the Actions runner. Keeping the automation in a private repo adds extra safety.
