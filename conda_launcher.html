Add an environment by path (for envs under AppData that can't be scanned)

If conda is installed under AppData, browsers block scanning that folder. Add those environments by typing their full paths here instead — one per line. Each line is the full path to an environment folder (the one containing python.exe).

Tip: the base environment is the Anaconda root itself. Named envs are usually under ...\anaconda3\envs\<name>.

Launcher folder & one-click Run setup

Launcher folder: not chosen yet.

Holds your saved list and the launcher files. Paste the full path and pick the folder — the path is needed inside the .reg; the pick grants write access.

How one-click Run works (set up once)
  1. Paste the launcher folder path and pick it. The page writes shortcuts.json, launcher.ps1 and install_protocol.reg there.
  2. Double-click install_protocol.reg once on this PC to register the condahub:// link.
  3. First Run click: Chrome/Edge asks to open the app — tick “Always allow”.
No registry install? Use Save .bat on any shortcut and double-click the file instead.
