What It Does

Built on a Raspberry Pi Pico W running MicroPython as a self-hosted Wi-Fi access point

⚡

Programmable Stimulation

Deliver output pulse trains with configurable pulse width, frequency, pulse count, trial count, and inter-trial interval — per cage or across all four at once.

📊

Live Event Monitoring

Each cage has a scrolling timeline that plots the output channel plus four digital inputs against the Pico's internal clock for a continuous 24/7 preview.

🔢

Edge-Based Counting

Every DIO channel counts events on either rising or falling edges, selectable live from the dashboard. Counts can be exported at any time.

⏺️

Recording with CSV Export

Assign Mouse IDs, hit record, and each cage's events are logged with computer time and trial-relative time. Data auto-downloads as per-cage CSV files on stop.

🔗

External Trigger Sync

Arm recording to wait for a 3.3V rising edge on GP20, so sessions start in sync with external equipment via a hardware interrupt.

🛑

Boot Safety Switch

Grounding GP22 at boot aborts the behavior app and drops to the REPL — a safe way to recover the board for editing in Thonny.

How a Session Works

From power-on to downloaded data

1

Connect

Join the Pico's Wi-Fi access point and open the dashboard in any browser.

2

Configure

Enter Mouse IDs, set stimulation parameters, and choose rising/falling edges per input.

3

Record

Start immediately, or arm the system to wait for the external GP20 trigger.

4

Export

Stop recording and the browser automatically saves timestamped CSV files per cage.
