FST_FP_synchronization — ZY-FP_Analysis

A MATLAB application with a user-friendly GUI that analyzes fiber photometry (FP) data from the Neurophotometrics system and aligns it with forced swim test (FST) behavioral data processed in Bonsai-RX. No coding experience is required to use it.

Repository

View FST_FP_synchronization on GitHub →

Overview

ZY-FP_Analysis was built to analyze fiber photometry data and synchronize it with FST behavioral scoring through a graphical interface, so users without programming background can process, align, and quantify neural activity around behavioral events. The workflow moves through a series of windows: selecting and previewing the FP signal, computing a filtered dF/F and z-score, synchronizing with the FST behavior file, finding signal peaks, linking peaks to behavioral bouts, and finally producing peri-event (aligned) analyses — with one-click export of all data and figures.

Features

  • GUI-driven analysis — no coding experience needed.
  • Loads Neurophotometrics FP data (.csv) and FST behavior files scored in Bonsai-RX.
  • Signal cropping, zero-phase filtering (filtfilt), and dF/F computation.
  • Z-scoring with multiple methods (baseline, entire trace, median) and optional manual mean/std.
  • Frame-accurate synchronization of behavioral bouts to the photometry timeline.
  • Peak detection with prominence-based thresholding and binned frequency/amplitude stats.
  • Linking of detected peaks to individual mobility/immobility bouts with per-bout statistics.
  • Peri-event heatmaps, mean/SEM traces, and peak raster plots around behavior onsets.
  • One-click export to Excel, PDF, and editable MATLAB .fig files.

Requirements

Software: MATLAB (the app installs as a .mlappinstall app).
Input data: Fiber photometry .csv recorded on a Neurophotometrics FP system, and (optionally) an FST behavior file scored in Bonsai-RX.

Installation

Clone the repository:

git clone https://github.com/addy9908/FST_FP_synchronization.git

Then install the app in MATLAB by opening the ZY_FP_Analysis_JHU.mlappinstall file (double-click it or use the Apps tab → Install App). Once installed, launch it from the MATLAB Apps toolbar.

Workflow

1. Select the FP file

Use Browser to locate the folder, then choose the fiber photometry data (.csv) recorded on the Neurophotometrics system.

2. Preview window

Once valid data is selected, the raw FP data populates the Preview window. Here you can crop the photometry data to a window of interest, apply a zero-phase filter (filtfilt; the default filter window is 4, entered as an even number, where 0 means no filter), select which signal to analyze, and click Update Filtered to update the final dF/F signal used for later analyses. After choosing the signal, you can enter a MouseID (e.g. M01_H_S1) that will be included in exported filenames.

3. Filtered dF/F window

This window shows the final dF/F signal that will be z-scored and aligned to the FST data. Click Update Filtered again to refresh the view whenever parameters change.

4. zScore window — synchronize FST + FP

Select the FST behavior file to populate the left table with time, code, and class data. Check Include FST to synchronize the FST and FP recordings; the right table then shows, for each bout:

  • Time — start time of the immobility or mobility bout.
  • Code — the behavior name (immobility, mobility, etc.).
  • Class — the number associated with the behavior.
  • Duration — length of the bout in seconds.
  • Time_s — the bout start in seconds within the photometry data (closest FP timestamp to the video timestamp).
  • Index — the index in the FP data where the bout starts.

After checking the box, two plots appear, the first being the cropped, filtered, z-scored dF/F signal with manual immobility bouts overlaid. The Plot button re-draws the figures with any new settings.

5. Peak Find (Habituation) window

Set the parameters for peak-finding, which apply both to peaks across the whole trace and to statistics during the habituation period:

  • Habituation ends (min) — how long the habituation period lasts (default 2 min). The start point is where you cropped from the beginning; for example, cropping at 4800 frames at an effective 20 fps gives 240 s (4 min), so a 2-minute habituation runs from 4 to 6 minutes.
  • Minimum Peak Prominence — the threshold separating authentic peaks from noise. Prominence measures how much a peak stands out by its height and position. Because FP signals differ between subjects (surgery, viral expression, probe location, etc.), this value should be tuned per animal to maximize true peaks and minimize false ones.
  • Bin Size (Seconds) — used in peak-frequency calculations (default 20 s).

Clicking FindPeak fills the Peak Finding Data table with: Time_s (time of the peak in seconds, including the cropped period), Time_m (same in minutes), PeakIndex (index of the peak, excluding the cropped period), PeakHeight, PeakWidth, and Prominence. It also produces a plot: the top panel shows the z-scored dF/F within the habituation window; the bottom-left shows average peak amplitude per bin; the bottom-right shows peak frequency per bin (peaks divided by bin length).

6. Peak-FST window

Clicking Link Peak-FST groups peak information into each FST behavioral episode. Columns 1–6 are cloned from the synchronized zScore table (Time, Code, Class, Duration, Time_s, Index), plus:

  • Count — number of peaks within the bout duration.
  • Max_amplitude — maximum peak amplitude in the bout.
  • Mean_amplitude — mean peak amplitude in the bout.
  • Sem_amplitude — standard error of the mean amplitude.
  • Frequency — peaks per second, using each bout's duration.

This also produces a four-panel plot. In the left scatter plots, mobility bouts are blue circles and immobility bouts are red: the top-left plots peak frequency vs. event duration and the bottom-left plots peak amplitude vs. event duration, helping reveal clusters. The right panels are box plots comparing mobility vs. immobility for peak frequency (top) and peak amplitude (bottom), each annotated with a p-value.

7. Align events window (peri-event analysis)

The final window examines behavior with a peri-event method, looking at the time before and after each behavior. Inputs:

  • Immobility events to Remove (,) — remove specific bouts by index, comma-separated (e.g. 3,15,61). Note this may introduce bias.
  • before_event_time (s) and after_event_time (s) — the window analyzed before and after each bout.
  • Choose Z-Scoring Method — Baseline (default; uses the pre-event period mean applied across the trace), Entire Trace (standard MATLAB z-score), or Median (z-score against the peri-event median).
  • Heatmap Sorted By — None (chronological), Maximal (by peak z-score), or Duration.
  • includeNA — whether to include bouts containing NaN values. NaNs arise from overlapping bouts within peri-event windows; overlapping portions are replaced with NaN. Checking includeNA plots mean/SEM across timepoints that contain NaNs (NaNs excluded from the calculation itself); unchecking plots only NaN-free timepoints, giving a cropped graph.

The event plot shows a heatmap plus a mean/SEM trace for both immobility onset and mobility onset. Each heatmap row is one bout, colored by z-score (white space marks NaN locations). A companion raster plot shows the peaks within each episode — line position for peak timing, color for amplitude — with binned frequency and amplitude (0.5 s) summarized below. Click Align Event to re-plot with new parameters at any time.

8. Data Process panel

This panel lets you lock the file-selection and Preview windows to prevent accidental changes, define the Mouse ID for export, and enable manual zScore to apply a predefined mean and standard deviation (for example, values from a previous analysis) when z-scoring the whole trace.

Exporting results

When finished, click Export All in the Data Process panel (upper-right). Exports include the selected signal name and Mouse ID in the filenames, and produce three outputs: all data in an Excel file, the relevant graphs in a single PDF, and the same graphs as editable MATLAB .fig files for later manipulation.
