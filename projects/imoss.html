iMOSS — Immobility/Mobility Optimized Scoring System

An open-source platform for high-resolution immobility scoring in the tail suspension test (TST). Originally developed for the TST, it can also be applied to other types of binary behavior scoring.

Repository

View iMOSS on GitHub →

Overview

iMOSS is a flexible, open-source, low-cost platform for precise quantification of mobility and immobility in rodent stress-coping behavior. It comprises two independent instruments:

  • iMOSS-MV — a video-based, frame-by-frame manual-scoring tool that lets you annotate the exact onset frame of each binary event, overcoming the temporal imprecision of conventional stopwatch scoring.
  • iMOSS-AS — a sensor-based automated instrument that detects immobility/mobility bouts from a load-cell signal at high sampling resolution, using a machine-learning optimized detection threshold.

The two tools can be used independently or together, and the automated output has been shown to align closely with careful manual scoring while remaining sensitive to pharmacological manipulation.

Features

  • Frame-level manual annotation of binary behavioral events (iMOSS-MV).
  • Automated, sensor-based bout detection at high sampling rate (iMOSS-AS).
  • Machine-learning optimized threshold for automated immobility/mobility detection.
  • Low-cost, scalable hardware built around common load-cell amplifiers.
  • Applicable beyond the TST to other binary behavior-scoring paradigms.
  • Exports structured data for downstream statistical analysis and plotting.
  • Fully open source under the MIT license.

System requirements

iMOSS-MV and iMOSS-AS are written in Python and use widely available libraries: OpenCV, Tkinter, NumPy, Pandas, Pillow, SciPy, and PyExcelerate. The automated hardware side (iMOSS-AS) uses an Arduino-compatible microcontroller reading HX711 load-cell amplifiers via the HX711_ADC library.

Software: Python 3.x, plus: opencv-python, numpy, pandas, pillow, scipy, pyexcelerate (Tkinter ships with most Python installs).
Hardware (iMOSS-AS): Arduino-compatible board, HX711 load-cell amplifier(s), load cell(s), and the HX711_ADC Arduino library.

Installation

Clone the repository:

git clone https://github.com/addy9908/iMOSS.git
cd iMOSS

Install the Python dependencies (a virtual environment is recommended):

pip install opencv-python numpy pandas pillow scipy pyexcelerate

For iMOSS-AS hardware, install the HX711_ADC library through the Arduino Library Manager, open iMOSS_AS_V1.ino in the Arduino IDE, and upload it to your board. Load-cell settling time and signal filtering can be adjusted in the library's config.h.

See the repository's own documentation for the authoritative, up-to-date installation steps.

Usage

iMOSS-MV (manual video scoring): record your TST session (for example as an .avi file), launch the iMOSS-MV application, load the video, and step through frame by frame to mark the onset of each mobility/immobility event. The tool records the exact frame for each transition and exports the scored data.

iMOSS-AS (automated sensor scoring): mount the animal apparatus on the load cell(s), run the uploaded Arduino sketch to stream force data, and use the iMOSS-AS software to process the signal and classify immobility/mobility bouts using the optimized threshold.

Pairing a frame-to-time mapping (e.g. a .csv exported during acquisition) with the video gives precise timing for each scored frame.
