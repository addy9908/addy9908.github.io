Mouse Lifespan Event Log

A LabArchives notebook widget for logging the full lifespan of a mouse — recording key identifiers and every event across its life, with dated, detailed notes. Especially useful for tracking behavioral testing timelines.

Overview

This plugin provides a structured event log for individual research mice inside a LabArchives electronic lab notebook. It captures each animal's core identifiers — Mouse ID, date of birth, and genotype — and maintains a running, dated record of every event in the animal's lifespan (procedures, behavioral tests, observations, and so on), each with a detailed note. The widget has a display mode that presents a clean, read-only summary of the animal and its event history, and an edit mode for adding or updating entries.

Features

  • Records core mouse identifiers: Mouse ID, date of birth, and genotype.
  • Chronological event log — each entry has a date, an event, and a detailed note.
  • Designed with behavioral testing timelines in mind.
  • Separate display and edit modes for clean viewing and easy data entry.
  • Two-part, self-contained HTML + JavaScript — paste directly into a LabArchives widget.

Installation

The plugin has two parts — an HTML block and a JavaScript block — that go into the matching sections of a LabArchives widget. To install:

  1. Click the three dots (⋮) in the top-right corner, then Widgets → Widget Manager.
  2. Click + New Widget.
  3. Enter a Widget Title under “Widget Information.”
  4. Paste each part of the code into its corresponding section of the Code Editor (HTML into the HTML area, JavaScript into the JavaScript area).
  5. Click Save Changes.

Once saved, the widget can be added to a notebook page, where you can switch between display and edit modes.
