How to add a document

Documents are listed in documents.json. You can either store the file in the repo (e.g. in an assets/docs/ folder) and point to it, or link to a file hosted elsewhere (Google Drive, SharePoint, Dropbox) by pasting its share URL.

  1. If storing in the repo: upload your file (PDF recommended for in-browser preview) into assets/docs/.
  2. Click Edit documents.json on GitHub above and add an entry:
{
  "title": "My SOP name",
  "url": "assets/docs/my-sop.pdf",
  "category": "SOPs",
  "type": "pdf",
  "desc": "Short description"
}

Put a comma after the previous entry's }, keep everything inside the outer [ ], and commit. The page updates within about a minute.

Fields: title, url, category (groups documents), type (pdf, image, doc, sheet, or link — controls the icon and preview), and optional desc. PDFs and images preview in-page; Word/Excel files download.
